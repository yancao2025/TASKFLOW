# TaskFlow

Ứng dụng quản lý công việc — giao diện "Giấy & Mực", chạy tốt trên điện thoại và máy tính.

- Đăng nhập/đăng ký bằng email
- Thêm/sửa/xóa công việc, checklist, ưu tiên, danh mục
- Dự án, lịch, thông báo
- Backend: Supabase (dữ liệu riêng theo từng tài khoản)

Mở `index.html` trên trình duyệt hoặc xem bản live qua GitHub Pages.
