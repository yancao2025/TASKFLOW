Bảng việc

Bản xem thử. Dữ liệu mẫu, mọi thay đổi chỉ nằm trên trình duyệt này và không được lưu. Đăng nhập để dùng dữ liệu thật
Chưa có cột trạng thái / ngày bắt đầu. Kanban vẫn chạy theo trạng thái suy từ việc xong/chưa xong, Gantt lấy ngày từ hôm nay. Chạy migration 4 trong SQL Editor của Supabase để bật đầy đủ, rồi tải lại trang.
-- xem file supabase-migration-4.sql trong thư mục TaskFlow
alter table tasks add column if not exists status text
  not null default 'chua-lam'
  check (status in ('chua-lam','dang-lam','duyet','xong'));
alter table tasks add column if not exists start_date date;

Kéo thanh để dời ngày, bấm vào thanh hoặc tên việc để sửa. Vạch đỏ là hôm nay.

Nhập công trình từ Sheet tracker

Trong Google Sheets: mở sheet “Theo dõi công trình” → Tệp → Tải xuống → CSV. Mở file CSV, chép toàn bộ, dán vào ô dưới. 6 cột theo đúng thứ tự: TÊN CÔNG TRÌNH, THỰC HIỆN, LOẠI, HẠN GIAO, HOÀN THÀNH, GHI CHÚ. Hàng đầu tiên là tiêu đề sẽ được bỏ qua.
